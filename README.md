# Cup Club — Inkside Community

A production-oriented fan-community web app with a modern social product underneath an original 1930s rubber-hose inspired art direction.

## V4 visual direction

V4 turns WebGL from a landing-page decoration into a navigation language:

- cinematic Three.js landing scene
- route-specific 3D dioramas
  - casino / high-score room for Leaderboards
  - radio studio for Messages
  - contract desk for Challenges
  - trophy cabinet for Achievements
  - miniature community island/map for Communities
- right-rail 3D scene changes by route
- film-iris route transition with destination title and clapper card
- subtle ink cursor trail on desktop
- pointer-reactive parallax in the 3D scenes
- dimensional card tilt + moving light reflection
- automatic animation pause when scenes leave the viewport
- reduced-motion and mobile fallbacks

All 3D props are procedural/original. No official game meshes, sprites, fonts, music or character art are bundled.

## Stack

Next.js 16, React 19, TypeScript, Three.js, GSAP, Supabase and Vercel.
